# Timothy Ojebiyi - Portfolio

Personal portfolio site, live at [timothyojebiyi.com](https://timothyojebiyi.com).

Built with Next.js (App Router), React, Tailwind CSS and Framer Motion, and hosted on Vercel.

## Run locally

```bash
npm ci
npm run dev
```

The site runs at http://localhost:3000. Use `npm run build` for a production build and `npm run lint` to lint.

## Where things live

- `src/components/Projects.jsx`: project list, including GitHub and live demo links
- `src/components/AboutExperience.jsx`: education and experience
- `src/components/Skills.jsx`: skills and tech stack
- `src/lib/site.js`: site URL, title and description used for metadata
- `public/documents/`: downloadable CV
